# Master Record App (Flutter)

Standalone Flutter + Riverpod client for the Master Record backend.
This is a completely independent project — no BSecure code, modules,
or dependencies are included.

## Setup

```bash
cd master_record_app
flutter pub get
```

### Point the app at your backend

Edit `lib/core/constants/api_constants.dart`:

- Running on the **Android emulator** against a backend on your dev
  machine: leave `environment = ApiEnvironment.androidEmulator`
  (uses `http://10.0.2.2:5000` automatically).
- Running on a **physical device**: set
  `environment = ApiEnvironment.physicalDevice` and put your computer's
  LAN IP in `_physicalDeviceBaseUrl` (e.g. `http://192.168.1.10:5000`),
  keeping both the phone and computer on the same Wi-Fi network.
- **Production**: set `environment = ApiEnvironment.production` and put
  your deployed HTTPS backend URL in `_productionBaseUrl`.

This file is the single source of truth for the backend URL — nothing
else in the app hardcodes it.

### Run

```bash
flutter run
```

### Build a release APK

```bash
flutter build apk --release
```

The APK will be generated at:
`build/app/outputs/flutter-apk/app-release.apk`

> Building the actual `.apk` binary requires the Flutter SDK and Android
> build tooling on your machine — that step can't be executed inside
> this chat sandbox (no Flutter SDK, no network access here). The steps
> above are exactly what to run locally or in CI to produce it.

## Notes

- Reference ID (`MP-000001`, ...) is always generated by the backend.
  The app only ever *displays* it — there is no field to type or edit it.
- Android permissions for camera / photo library access are declared in
  `android/app/src/main/AndroidManifest.xml`.
- `usesCleartextTraffic="true"` is set for local HTTP development
  against `10.0.2.2` / a LAN IP. Remove it once you switch to an HTTPS
  production backend.
